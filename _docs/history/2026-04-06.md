# 2026-04-06 — Blender 합성 데이터 대량 생성 (v65~v70)

## 작업 요약

실제 추론 실패 사례를 분석하여, 부족한 학습 데이터 영역을 집중 보강하기 위해 Blender 렌더링 파이프라인으로 대량 합성 데이터를 생성함.

---

## 1. 실제 추론 실패 원인 분석

사용자가 실제 환경(연구실) 사진으로 DOPE 추론 실행 → 주요 실패 케이스 파악:
- **위에서 찍은 팔레트** (탑다운 뷰): belief map이 팔레트를 못 찾음
- **프레임 가장자리에 걸린 팔레트**: 센터도 못 찾음
- **어두운/검은 팔레트**: 기존 합성 데이터는 밝은 색(초록, 파랑, 주황)만 있었음

## 2. config/synthetic/blender.yaml 수정 내역

### 카메라 뷰 모드 추가
- `top_down` (weight 0.25): height_base=[3.0,5.5], height_scale=[0.3,0.6], 팔레트를 60-85° 각도로 내려봄
- `top_down_crop` (weight 0.15): look_offset=[0.25,0.60], edge_crop_prob=0.45 — 프레임 가장자리 잘림 시뮬레이션
- 기존 모드 weight 재조정: close_full 0.20→0.12, close_crop 0.20→0.15, mid 0.35→0.18, far 0.25→0.15

### 팔레트 색상 어둡게 변경
- **Before**: 밝은 초록(0.27), 파랑(0.44), 주황(0.60) 등
- **After**: black(0.02), charcoal(0.05), dark_gray(0.08), dark_green(0.02,0.06,0.03), dark_blue(0.02,0.03,0.08)
- wood 계열도 dark_stain, ebony, charred_wood 등으로 교체

### 조명 어둡게
- `exposure_range_ev`: [-0.2, 0.2] → [-1.5, 0.2]
- `hdri_base_strength`: 1.0 → 0.6

### 빈 팔레트 추가
- `empty_pallet_probability: 0.15` 신규 추가 (15% 확률로 적재물 없는 프레임)

- 초기에 0.30으로 낮춤 → 사용자가 0.60 유지 지시 (PnP에 최소 3-4 non-coplanar keypoint 필요)

## 6. 미해결 사항

- 합성 데이터로 학습 후 실제 환경 추론 결과: PnP 성공률 49.5%, Filter B 통과 2.7%
- 특정 각도/거리에서만 잘 됨 — 일반화 부족
- **Domain gap**이 근본 원인으로 파악됨: 합성(어두운 창고) vs 실제(밝은 실내 연구실)
