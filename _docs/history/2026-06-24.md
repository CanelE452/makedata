## v3 후처리 1단계 (postprocess_v3) — batch_000 게이트 통과, 전수는 사용자 직접

기존 1만 장 v3(`train_palletobj_v3`) baseline 보존, 비파괴 후처리. 사용자 요청으로 1만 장 전수는 사용자가 직접(스크립트만 완성).

### 신규
- `scripts/data_prep/postprocess_v3.py`: RLE→binary mask + keypoint 상태필드(heatmap_valid/vector_valid 분리) + surface keypoint 재투영 + audit. 출력 `train_palletobj_v3_post_v1/`(batch 구조, 비파괴).
- `scripts/data_prep/gen_surface_fps_v1.py`: visibility-constrained surface FPS 8점.

### ★projection convention 확정 (재사용 핵심)
opencv(Y-,Z-): `Xc=Rcw^T(Xw-camt); Xcv=Xc*[1,-1,-1]; u=fx*Xcv.x/Xcv.z+cx; depth=Xcv.z`. batch_000 world-point reproj median 0.02px·p99 0.08px (vs projected_cuboid).

### V 정의 통일 (25.4 vs 56 혼동 해소)
`V_geom = sum(in_front AND inside_image for box_corners_8)`(occlusion 무관). batch_000 V<8=25.1%(= 사용자 25.4%). 이전 56%는 `num_corners_visible`(in_frame AND unoccluded, occlusion 포함).

### surface_fps_v1
면적비례 샘플→밑면제외→운영시점 visibility raycast(416/800)→FPS 8. planarity 0.095(= box corner 0.092, 납작 팔레트 한계, 결함 아님). OBJ→world scale/축 검증 0.047mm. `train_palletobj_v3_post_v1/surface_fps_v1.json`.

### keypoint 상태필드 정책(사용자 피드백 반영)
heatmap_valid=projectable∧inside / vector_valid=projectable(화면밖도 vector 학습) / mask_support_fraction(box corner는 실루엣 경계라 fraction 보존, inside_image=False면 null) / visibility_source="mask_window_proxy"(진짜 visibility 아님). xy clamp 금지.
batch_000(1000장) gate 통과: mask 100%, reproj p99 0.08px, surface overlay 정상.

## add-on 렌더 (train_palletobj_addon_v1) — D435i 정합 + 시점/크기/센서 DR

real gap 보강 ~6천 장. `gen_palletobj_scenarios.py` 수정 + `camera_effects.py` 신규.

### A. ★카메라 D435i 정합 (real gap 핵심)
- D435i Color 640x480 factory intrinsic: fx=605.9065 fy=605.9698 cx=317.5962 cy=256.2923, distortion=0 (pyrealsense2 실측).
- lens 고정 = fx*36/640 ≈ 34.08mm, sensor_fit HORIZONTAL.
- **shift convention 확정(empirical, reproj du/dv<1px)**: `cx = W/2 - shift_x*W` (x 뒤집힘!), `cy = H/2 + shift_y*W`. → `shift_x=(W/2-cx)/W`, `shift_y=(cy-H/2)/W`. (둘이 부호 반대 주의.)
- `intrinsics()` D435i 고정 출력. 검증: reproj du 0.015px / dv 0.034px.

### B. 시점·크기 보강 (sample_random_scenario)
- azimuth `clock=[3,6,9]` → uniform 0~360 (공백 30~150° 등 채움). generate_frame은 `scenario["azimuth_deg"]` 우선(없으면 CLOCK fallback).
- elevation 12~60 → 0~60 (낮은 지게차 시점).
- projected size 5구간 균등: `surf_dist = fx*1.3/uniform(size_bin) - 0.7`, bins [40-64,64-128,128-256,256-384,384-560].
- lens 가변 제거(D435I_LENS 고정).

### C. 외형 DR
- `camera_effects.py` (RGB only, mask/keypoint 무관, post): WB/color-cast, vignette, defocus/motion blur, sensor noise, JPEG. render_frame에서 mask 렌더 후·overlay 전 `CE.apply(img_path, frame_idx)`.
- 조명: HDRI 7종 + exposure + post WB(=색온도 효과). 팔레트 재질 오염/긁힘은 **사용자가 스킵**(photogrammetry라 노후화 이미 반영).
