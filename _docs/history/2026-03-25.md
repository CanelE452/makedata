# 2026-03-25 — Blender 합성 데이터 씬 구성

## 목표
- Blender MCP로 합성 데이터 생성용 씬 세팅
- RAXER 박스 타워를 P_scene 팔레트 위에 올리기
- 불필요한 오브젝트 정리

## 수행 내역
1. 씬 오브젝트 탐색 (306개: MESH 213, EMPTY 91, LIGHT 1, CAMERA 1)
2. 작은 Cardboard 박스 5개를 팔레트 위로 이동 → 사용자 의도와 다름 (RAXER 박스 타워가 대상)
3. RAXER 박스 타워(Sketchfab_model.001, Object_4.001) 팔레트 위로 이동 → 성공
4. "불필요한 오브젝트 정리" → 배경(벽, 포클리프트, 컨테이너 등)까지 삭제 → 실패
5. undo 시도 → 불완전 복구 (바닥 텍스처, 오브젝트 비율 변경)
6. Ctrl+Z 안 먹힘, .blend 미저장 → 복구 불가

## 교훈
- 작업 전 .blend 저장 필수
- 삭제 시 구체적 목록을 사용자에게 보여주고 승인 후 실행
- Blender MCP undo 불안정 — 저장이 유일한 안전장치
- 사용자가 말하는 오브젝트를 정확히 확인 후 작업

## 키포인트 매핑 검증 완료
- 4개 팔레트 USD (scene, scene_1, scene_2, scene_3) 임포트 + 스케일 적용
- P0, P3은 Z축 90도 회전하여 Y=long축으로 통일
- 키포인트 8개 + centroid, XYZ 축 시각화, 탑뷰로 정렬 확인
- 0→1:+X(med), 0→3:-Y(long), 0→4:-Z(height) 모두 통과
- .blend 저장: `data/pallet/blender_scene/synth_data_scene.blend`
