## 5. ★ Stage 2-C2 보고 정정 2건

### (a) C2C verify 가 failures 3 이다

```
S2C2002  RELPATH_SET extra=['synth_data_scene_portable_stage2c2.blend',
                            'synth_data_scene_portable_stage2c2_candidate.blend1']
S2C2002  FILE_COUNT 175 != 173 / TOTAL_BYTES 4554353915 != 3836556170
```

`missing=[]`, SHA256 1,334건 **mismatch 0** — 데이터 손상은 아니다. extra 2개는 Stage 2-C2 가
정상적으로 만든 파일이다. 그러나 2-C2 보고서에 적은 "C2C failures 0" 은 **candidate 생성 전**
측정값이었고, 승격 후에는 strict verify 가 필연적으로 실패한다. 그 보고는 부정확했다.

조치: `--verify` 기본 동작(엄격)은 그대로 두고 `--allow-destination-additions` 를 추가해
"없어진 파일 0 + SHA256 mismatch 0" 이라는 진짜 불변식만 보게 했다. 나머지 5개 원장은
strict 로도 failures 0, 트랜잭션 unit 69개 전부 통과.
