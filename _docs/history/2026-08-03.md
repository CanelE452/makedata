## 1. 팔레트 치수 랜덤화 (신규 기능)

### 배경 — 왜 필요했나

Figure 3 를 만들다 발견: 팔레트 치수가 **이산값 3~4개뿐**이었다.  에셋 4종을 그대로
쓰고 크기를 전혀 흔들지 않았기 때문이다.  게다가 **4종 모두 KS T-11 규격(정사각형)이
아니었다.**

```
종류        실측 치수 (m)              long:short:height    바닥면 종횡비
Pallet_0   1.190 x 0.992 x 0.149      8.0 : 6.7 : 1        1.20
Pallet_1   1.192 x 0.991 x 0.136      8.7 : 7.3 : 1        1.20
Pallet_2   1.178 x 1.002 x 0.184      6.4 : 5.5 : 1        1.18
Pallet_3   1.269 x 0.847 x 0.152      8.3 : 5.6 : 1        1.50  <- 가장 심함
KS T-11    1.100 x 1.100 x 0.150      7.33 : 7.33 : 1      1.00 (정사각형)
```

★조사 중 **"비균등 스케일이 걸려 있다"고 잘못 판단했다가 정정**했다.  W/D 가 각각
값 2개뿐이고 서로 자리만 바꾸는 것 — 스케일 랜덤화는 **아예 없었고**, 에셋 자체가
직사각형이었다.  (판별법: `dimensions_m` 고유값 개수를 세면 바로 드러난다.)

### 구현

- `scene_placement_v2.py`
  - `PALLET_SCALE_JITTER_SIGMA = 0.10` / `PALLET_SCALE_JITTER_MAX = 0.20`
  - `sample_pallet_scale_ratio(rng)` — 1.0 중심 절단 정규분포.  rejection 16회 후 clamp
    (무한 루프 방지).  KS 근처가 많고 벗어날수록 드물다.
  - `scaled_target_dims(base_dims, ratio)` — **균등 배율만** (형상 유지)
  - `_STAGES` 에 `"pallet"` 추가.  stage 이름으로 독립 해시되므로 **기존 stage seed 는
    불변**(재현성 보존).
- `v2_realize.py`
  - `_select_and_place_pallet(pallet_type, translate, scale_ratio=1.0)` —
    `get_normalized_scale(..., target_dims=...)` 로 전달.  **`target_dims` 인자는
    이미 있었다**(`pallet_geometry.py:136`) — 새로 만들 필요 없었음.
  - `_realize_constrained` 에서 `random.Random(stage_seeds["pallet"])` 로 뽑아 적용.
  - `constrained_metrics` 에 `pallet_scale_ratio` 기록.
- `run_v2_scene_logic.py` — record 2곳에 `pallet_scale_ratio` 추가.

### 검증

- unit **976 passed / 0 failed** (신규 8종)
- 실제 렌더 12장: ratio 12/12 기록, dims 연속 변화, **종횡비 종류별 고정**(형상 유지)
- 1만 장 전수: 배율 0.800~1.200, 중앙 0.996 — 설계대로

★**작업 사고**: metrics 를 잘못된 dict(반환 dict)에 넣어 첫 렌더에서 ratio 가 기록되지
않았다.  `constrained_metrics`(`v2_realize.py:2930` 부근)로 옮겨 재렌더해 해결.

**안전성 사전 확인**: `PALLET_TOP_Z` 는 정의만 있고 v2 경로 미사용,
cargo 배치·keypoint·cuboid 는 전부 **측정된 geometry** 를 쓰므로 스케일이 자동 반영된다.

## 6. 이번 구간에서 내가 틀렸다가 정정한 것

1. **"비균등 스케일이 있다"** -> 스케일 랜덤화가 **아예 없었다**.  W/D 고유값이 각 2개뿐이고

   둘 다 과소평가했다.
3. **"앙각이 양극단"** -> 저앙각 단조 편중.  몽타주(maximin)를 분포로 오인.
4. **"밝기가 문제"** -> 실물은 역광 실루엣이고 어두운 톤은 설계 의도.  문제는 **여유 0**.
