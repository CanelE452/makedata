## 바닥 텍스처 패턴 크기 (UV scale) 비교 렌더 — 적정 metres_per_tile 탐색

### 배경
바닥 패턴(벽돌/타일/포장석)이 팔레트(1.1m)보다 커 보여 비현실적. 원인=`blender_config.py:216`
`FLOOR_UV_SCALE_RANGE = (4.0, 9.0)` (metres per texture repeat). metres_per_tile=텍스처 이미지 1장이
차지하는 world 미터. 이미지엔 벽돌/타일이 여러 개 들어있어 개별 요소 ≈ metres_per_tile/(이미지당 개수).
4~9m면 개별 벽돌 ~0.3~0.9m = 팔레트만함. 직전 `_hide_bg_ground` 가림버그 수정으로 작은 UV에서도
회색 mush 안 생기는 조건 확보됨 → 작게 줄일 수 있게 됨.

### 작업
신규 `scripts/data_prep/blender/_render_floor_uv_compare.py`:
고정 팔레트(scene_2 목재, ~1.1m)+카메라(elev34/az40/dist4.0 oblique)+HDRI에서
텍스처 3종(red_brick, tile_white, cobblestone_floor_08) × metres_per_tile 5값(1.0/1.5/2.0/3.0/6.0)
= 15장 Cycles 렌더. 같은 카메라라 팔레트 크기 고정, 바닥 패턴만 변함.
`force_floor()`가 `_hide_bg_ground`+`_build_floor_material(uv_scale=PLANE_SIZE/mpt)` 직접 호출.
config 미변경(비교용 임시). 시트+패턴대비(grey std) = `_make_floor_uv_sheet.py` (cv2=pathfinder env).

### 결과 (실제 이미지 전수 로드 판정)
패턴 대비(floor ROI grey std, 낮을수록 mush):
```
texture                  mpt1.0  mpt1.5  mpt2.0  mpt3.0  mpt6.0
red_brick                   8.3     9.0     8.8     8.8    10.3
tile_white                  9.8    14.1    16.0    17.4    17.9
cobblestone_floor_08       19.5    21.0    21.9    22.1    23.9
```
std가 작은 mpt에서도 안 무너짐 → mush 없음(가림수정 효과 확인).
육안 판정:
- mpt=6.0(현 범위): 벽돌/포장석 개별 요소가 팔레트 폭의 ~절반(0.4~0.6m) = 비현실적 거대. **사용자 불만 재현 확인.**
- mpt=3.0: 아직 약간 큼(요소 ~0.25~0.35m).
- mpt=2.0: 벽돌 ~0.15~0.2m, 팔레트 아래 여러 장 들어감 = 자연스러움.
- mpt=1.5: 타일/포장석 ~0.1~0.3m, 자연스럽고 거리에서도 해상됨(mush X).
- mpt=1.0: 가장 작고 자연스러움, 여전히 또렷(std 유지).

**추천 적정 범위: metres_per_tile = 1.0 ~ 2.5** (요소가 팔레트보다 확실히 작고 mush 없음).
보수적 권장 기본값 `(1.0, 2.5)` 또는 `(1.2, 2.2)`.

주의: 전 프레임에 마젠타 색조 = `factory_yard_2k.hdr` 누락(별개 이슈, 본 gen_dataset_v4는
이 HDRI를 pool에서 drop함 — memory 39). 패턴 SIZE 판정엔 무영향.

### 확정 변경 위치 (사용자가 값 고른 뒤)
`scripts/data_prep/blender/blender_config.py:216` `FLOOR_UV_SCALE_RANGE = (4.0, 9.0)` → 고른 범위로 교체.
`randomize_floor`가 `random.uniform(*FLOOR_UV_SCALE_RANGE)` → `uv_scale=PLANE_SIZE/mpt`로 자동 반영.
주석(213~219줄: "LARGE tiles on purpose 4-9m")도 함께 갱신 필요.

### 저장 경로
시트: `data/pallet/_floor_uv_test/_sheet.png` (행=텍스처, 열=mpt 1.0/1.5/2.0/3.0/6.0)
개별: `data/pallet/_floor_uv_test/<tex>_mpt<val>.png` (15장)
스크립트: `_render_floor_uv_compare.py`, `_make_floor_uv_sheet.py`
