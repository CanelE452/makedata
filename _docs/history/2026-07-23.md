## E-단면 12키포인트(efront_kp12) 스킴 — 측정 → 결정 → 구현 (additive, gen 미배선)

파렛트 앞면 fork-entry 개구부 기반 12키포인트(외곽 4 + 개구부 4×2) 라벨 스킴. 읽기전용 측정으로 성립성 판정 → 설계 결정 → 모듈 구현·검증까지. **생성 파이프라인 무변경**(신규 모듈 + 검증 스크립트만).

### 1. 기하 측정 (read-only) → `data/pallet/_efront_12kp_check/`
- `efront_measurements.json` (8 레코드 = P0~P3 × long/short). nominal dims = `pallet_geometry.get_pallet_geometry()` 라벨 큐보이드(aabb=nominal ≤0.1mm). 측정법: full-depth 정사영 see-through + slab ε=0.10m 교차검증. v=0=world 바닥.
- **게이트 결과**: `P2 long = n_openings 0`. 블록 3개 사이 틈이 상·하 열려 닫힌 창 없음(상단 데크 v≈0.13~0.17에 있으나 블록보다 ~2.5cm 리세스 + long면 하단보드 부재). → **P2 닫힌 창은 short 면만**.
- 닫힌 2홀 6면: P0 long/short, P1 long, P2 short, P3 long/short (fill 0.96~1.00). P1 short=2홀이나 bottom_open(다리형, fill 0.928, corner_r 54mm).

### 2. 별건 확인 (read-only)
- **±면 대칭**: P0/P1/P2 축쌍 ±면 대칭(mirror-IoU≥0.96) → intrinsic 비율 **축쌍(2) 저장 충분**. P3만 ±D(W-span) ~1-2cm 오프셋(IoU 0.930) → sub-cm 필요시 P3만 물리면(4).
- **footprint 비율**: raw USD dims W:D = 정규화후 W:D 4자리 완전일치(uniform-fit이 aspect 보존). P2 near-square(1.0055)는 scene_2.usd 메시 고유(fit 아티팩트 아님). P0/P1/P3 = 1.20~1.21.
- **P2 에셋 한계**: P2 long이 리세스 데크+하단보드 부재로 실제 4-way 유로 블록팔레트와 다름 → **수정 안 함**, 논문 데이터 절 에셋 한계로 기록(다양성엔 무해 가능).
- **yaw**: P2는 개구부가 축별로 다름(닫힌↔열린)이라 C2(180°)만 대칭, C4(90°) 아님 → err_90 부당(실오류 면제), err_180 타당. 4팔레트 모두 C2. 현 repo엔 err_180/yaw 지표도 회전오차 eval 데이터도 없음(metrics.py 회전코드 dead=호출부0, evaluate_on_val.py는 PCK+2D reproj만, GT가 Isaac 프레임이라 3D 회전 스킵).

### 3. 결정 (사용자, option 1)
12kp는 '닫힌 2홀' 면에만 정의, P2 long 제외. P1 short는 bottom_open 변형 포함. 구현 보강: ①kp12_valid=의미(long/short) 아닌 **물리 면(메시 축)** 기준 ②±대칭 반영 축쌍(2) ③kp12_in_frame/visible 8코너 동일방식 ④front_face_axis 기록+long/short는 per-frame dims 파생. req③(intrinsic 비율×per-frame dims)은 ratio DR이 아핀이라 근사 아닌 정확.

### 4. 구현 — `scripts/data_prep/blender/efront_kp12.py` (신규, additive)
- `EFRONT_RATIOS` 테이블: 키 `"P{id}|{face_axis}"`(축쌍 2). **무차원 비율만**(opW/faceW, opH/faceH, side_margin/faceW, top_off/faceH, u_center[L,R], bottom_open, fill, corner_r). 무효면 valid:False(P2|D). `build_ratio_table_from_json()` 재현(baked==json, mismatch 0).
- `compute_efront_kp12(pallet_id, cuboid_corners_world, perm, K, R_w2c, t_w2c, actual_face_dims, image_wh, raycast_fn)`: FRONT 축을 perm canonical 인덱스집합(`{0,1,2,3}`→W-span / `{0,3,4,7}`→D-span)으로 **카메라-독립 복원**(P2 near-square 강건). kp12_valid=물리축 기준. 12kp 3D=외곽4(FRONT cuboid 코너)+개구부8(비율×per-frame faceW/faceH, mirror, bottom_open이면 v=0), K/R/t로 2D 투영(compute_annotation_v4와 동일 규약). kp12_in_frame/visible, opening_meta 반환.
