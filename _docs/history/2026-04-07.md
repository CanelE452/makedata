# 2026-04-07 — 실내 환경 합성 데이터 테스트 렌더링

## 작업 요약

실제 추론 환경(연구실)과 합성 데이터(창고/주차장) 간 domain gap을 줄이기 위해, Blender 씬에 실내 환경을 구축하고 10프레임 테스트 렌더링.

- PnP 성공: 93/188장 (49.5%)
- Filter B 통과: 5장 (2.7%)
- 가장 큰 원인: **배경 환경 차이** (카메라 각도 부족이 아님)

| 항목 | 합성 데이터 | 실제 환경 |
|------|------------|----------|
| 배경 | 창고/주차장 | 사무실/연구실 |

## 2. Blender 실내 환경 구축

### 생성한 오브젝트
- `IndoorFloor`: 24x24m 두꺼운 바닥 (밝은 회색, Base Color 0.38)
- `IndoorWall_Back/Left/Right/Front`: 4면 벽 (회색, Base Color 0.35)
- `IndoorCeiling`: 천장
- `IndoorBaseboard`: 검은 하단 몰딩
- `IndoorTable1` + legs: 접이식 테이블
- `IndoorStand`: 화이트보드 거치대 형태
- `IndoorLight1/2`: Area 조명 (500W, 300W)

### 방 크기/위치
- 중심: (-9, -9), 크기: 8x8x3m
- 팔레트 위치: Pallet_0 empty at (-9, -9, 0), 실제 bbox 중심은 (-8, -7, 0.07)

### 조명 설정
- HDRI: abandoned_games_room_01 (strength 0.3)
- Area lights: 천장에 2개 (실내 형광등 시뮬레이션)
- Sun light 비활성화

## 3. 팔레트 머티리얼 문제

### 실수: 원래 머티리얼 덮어씌움
- Pallet_0_mesh의 원래 머티리얼 `blinn1`을 `IndoorPallet_Mat`(단색 검정)으로 교체 → 팔레트 질감/디테일 상실
- **해결**: `bpy.ops.wm.revert_mainfile()`로 저장 파일 복원 후, 실내 환경만 재구축

### 색상 변경 (blinn1 노드 수정)
- `blinn1` 머티리얼의 Mix 노드(`조합`)에서 색상 변경
- Before: A=(0.004, 0.064, 0.017) B=(0.005, 0.073, 0.020) — 초록색
- After: A=(0.008, 0.010, 0.025) B=(0.012, 0.015, 0.035) — 짙은 네이비

### [해결됨] 팔레트 모델 문제
- `Pallet_0_mesh`(단순화 모델, 4K vertices)와 `Pallet_0` children(실제 모델, 413K vertices, Object_0~6)이 별도 존재
- `Pallet_0_mesh`를 숨기고 실제 children만 표시하여 해결
- 머티리얼: `PalletVariant_plastic_red_blinn1` → Principled BSDF Base Color 변경으로 색상 적용

## 5. 대량 렌더링 (test_indoor_v1)

### 독립 스크립트 작성: `scripts/data_prep/blender/render_indoor_data.py`
Blender CLI 백그라운드 실행용 스크립트. 모든 변형을 프레임마다 랜덤 적용:

- **바닥 색상 7종**: light_gray_tile, warm_beige, dark_concrete, medium_gray, epoxy_light, wood_floor, dark_tile
- **벽 색상 5종**: gray, light_gray, warm_white, blue_gray, dark_gray
- **팔레트 색상 5종**: black, charcoal, dark_gray, dark_green, dark_blue
- **카메라 모드 6종**: oblique, high_angle, close_low, cctv, top_down, far
- **조명**: 밝기 200~800W 랜덤, 30% 단일조명, warm/neutral/cool 색온도
- **팔레트 yaw**: 0~360° 랜덤 회전
- **가구 위치**: 랜덤 배치, 30% 팔레트 근처 occlusion
- **엣지크롭**: 20% 확률 프레임 가장자리 잘림
