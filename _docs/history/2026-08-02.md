### 이번 세션에서 내가 틀렸다가 정정한 것

1. **기준선 30.9 s/usable -> 실제 55.1** — pilot500 은 resume run 이라 `elapsed_s`(세션 단위)를
   `usable_delivered`(누적)로 나눴다. `run_v2_scene_logic.py:2128,:1892` 확인. 이에 따라
   병렬 배수도 1.6~2.3배 -> **2.6배**로 재계산.
2. **"거부 프레임 시간이 기록 안 됨" -> 이미 기록됨** — 최상위가 아니라 `record` 키 **안에**
   중첩돼 있었다(smoke100b: accepted 2,946s + rejected 2,855s ~= elapsed 5,507s).
3. **"context skip 미구현" -> 이미 구현됨** — 구버전 smoke100 레코드(field 부재=None)를
   미구현으로 오판. 현재 코드 run 은 100% skip.
4. **"최종 렌더가 순수 낭비" -> 아님** — stage 분해상 실패 프레임 시간은 탐색 70.5% + context 21.2%.
5. **"CPU 96스레드 경합이 원인" -> 아님** — threads=6 이 오히려 2.2% 느림.
6. **cargo/context 배치가 낭비 -> 아님** — 879 시도 중 655는 렌더 없는 기하 검사.
