### 2. Cuboid Annotation 정합 (핵심 작업)

**문제**: 팔레트마다 내부 메시 구조(로컬 축 방향, parent chain rotation)가 달라서 world space에서 cuboid 꼭짓점이 뒤집히거나 세로로 서는 현상 발생.

**시도한 접근 (실패 → 성공 순)**:
1. **World AABB** → 회전된 팔레트에서 cuboid가 비스듬히 정렬되지 않음 (FAIL)
2. **OBB (local bbox → world transform)** → Pallet_1의 parent chain 2x90° X rotation으로 height가 수평 Y로 매핑됨 (FAIL)
3. **World shortest edge** → 길이는 맞지만 방향이 수평이라 cuboid가 여전히 세로 (FAIL)
4. **Z-forced approach** (최종 성공):
   - Blender의 `bound_box` 8개 꼭짓점을 `matrix_world`로 world 변환
   - 3개 edge vector 중 shortest = height (팔레트는 항상 납작하므로)
   - Height를 pure Z 방향으로 강제 (`[0, 0, h_len]`)
   - 나머지 2개 edge는 XY 평면에 flatten (Z 성분 제거)
   - Z 제거로 길이가 0이 된 edge는 cross product로 복원
   - Z ground = `pallet_obj.location.z`로 설정

**검증 결과** (test_blender_v33/cmp6):
| 팔레트 | Width | Height | Depth | Z범위 | 상태 |
|--------|-------|--------|-------|-------|------|
| Pallet_0 | 998mm | 137mm | 1200mm | 0~0.137 | ✅ 정상 |
| Pallet_1 | 997mm | 137mm | 997mm | 0~0.137 | ✅ 정상 (이전 세로 문제 해결) |
| Pallet_2 | 1193mm | 218mm | 1200mm | 0~0.218 | ✅ 정상 |
| Pallet_3 | 100mm | 15mm | 991mm | 0~0.015 | ❌ bbox 너무 작음 (미해결) |

### 3. Pallet_0 신규 생성
- 기존: EMPTY 오브젝트로 메시 없음 → 렌더링 불가
- 해결: Pallet_1의 메시(`pallet_low`)에서 `bpy.data.meshes.new_from_object()`로 복제, Y-UP→Z-UP 변환을 꼭짓점에 직접 bake
- 구조: `Pallet_0(EMPTY) → Pallet_0_mesh(MESH, scale=1, pre-transformed)`

### 4. BVH Mesh Intersection 기반 겹침 감지
- `randomizers.py`의 `mesh_overlap()`: `mathutils.bvhtree.BVHTree.overlap()` 사용
- AABB margin 0.5m 사전 필터 + BVH 정밀 검사
- Static obstacle 수집: `_collect_static_obstacles()`로 고정 씬 오브젝트 AABB 캐싱
- 팔레트 배치 시 20회 retry로 겹침 회피

### 5. Ray Casting Visibility 체크
- `check_raycast_visibility()`: 팔레트 상면에 5x5 그리드 → `scene.ray_cast()` → 60% 이상 보여야 통과
- 팔레트/박스는 visible로 분류, 디스트랙터만 occluder로 취급

### 6. Domain Randomization 구현

| 항목 | 구현 | 설정값 |
|------|------|--------|
| 팔레트 종류 | `random.choices()`로 가중 샘플링 | plastic 60%, wooden 40% |
| 카메라 거리 | 1.5~8.0m 범위 | height는 distance에 비례 |
| Off-center | 50% 확률로 look_at을 팔레트 옆으로 shift | |
| HDRI | `data/pallet/hdri/`에서 5종 로드 | strength randomized |
| 배경 | industrial / parking_lot 번갈아 사용 | `BACKGROUND_KEYS` |
| 디스트랙터 | ±27~153° 각도 배치, AABB 0.5m margin | children hide/show 포함 |
| 박스 적재물 | 팔레트 위에 1~7개, 5종 shape profile | 높이별 스택 |

### 7. Rich Overlay 시각화
- `draw_overlay()`: 면 채우기(top=green, bottom=red), 축 화살표, edge 길이 라벨, 통계 패널(W/H/D, camera dist, visibility), axis legend
- Edge 그룹: top_edges, bot_edges, vert_edges per keypoint convention
