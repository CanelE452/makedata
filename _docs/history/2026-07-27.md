### 문서에 기록한 핵심 내용

- [확인] 전체 500 record, 렌더 435, 미렌더 65, 렌더 기준 all-pass 364/435=83.68%, 전체 record 기준 all-pass 364/500=72.80%를 분리해서 기록했다.
- [확인] baseline 2k와 새 rendered subset에서 관측된 gate fail rate 차이를 gate별로 기록하고 causal ablation이 아니라는 제한을 붙였다.
- [확인] 22개 chart 각각에 대해 파일 링크, 표본수/분모, 핵심 결과, 과해석 금지를 작성했다.
- [확인] controlled occlusion chart 09의 전체 target 기준 q95=0.3931과 rendered-only q95=0.1111이 서로 다른 분모라는 점을 별도 경고로 기록했다.
- [확인] chart 16/17은 `r.get(bin) or fallback` 때문에 정수 bin 0과 non-rendered fallback label이 분리되고, chart 18은 Boolean `False`가 `(missing)`과 합쳐지는 analyzer 문제를 발견했다. 현재 PNG 3개는 정량 주장에 사용하지 않도록 표시하고 `frame_metrics.csv`에서 rendered 435장을 다시 집계한 교정표를 문서에 넣었다.
- [확인] automated audit pass 493과 manual clean pass 286이 서로 다른 기준이라 모순이 아님을 기록했다.
- [확인] strict RGB decode failure 0과 non-rendered/missing RGB 65를 혼동하지 말아야 한다고 기록했다.
- [확인] 핵심 차트 6개와 representative contact sheet 7개를 문서에 직접 삽입하고, 각 그림에 표본수·용도·한계를 포함한 독립 캡션을 작성했다.
- [확인] collision 서술은 thumbnail 육안 판정과 분리했다. exact BVH가 평가된 497 record에서 collision 0건이며 anchor reject 3건은 미측정이라고 명시했다.
- [확인] baseline 2k와 새 500-record 진단은 runner, proposal, acceptance가 달라 causal ablation이 아니라 descriptive comparison이라고 명시했다.
- [확인] 논문/README용 figure 묶음과 바로 쓸 수 있는 핵심 문장을 추가하되, 오류가 있는 chart 16/17/18은 재생성 전 제외하도록 했다.
