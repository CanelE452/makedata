### 구현 파일과 핵심 함수

- `scripts/data_prep/blender/scene_placement_v2.py`
  - scene role/contact matrix, diagnostic-mode policy, stage seed, AABB broad phase, source-mask decomposition, constrained metadata validation을 구현했다.
  - explicit occluder의 target-side 계약, bounded search stage, asset alias/disjointness 정책을 추가했다.
- `scripts/data_prep/blender/scene_visibility_v2.py`
  - Blender BVH 충돌, support ray, camera clearance, context/occluder image-space 배치 기능을 구현했다.
  - `fresh_world_aabb()`에서 hierarchy visibility와 dependency graph를 갱신하여 hidden child의 이전 프레임 transform이 AABB에 남는 교차 프레임 누수를 수정했다.
- `scripts/data_prep/blender/v2_pipeline.py`
  - constrained 경로를 opt-in으로 연결했다. `solve_placement(..., placement_mode="legacy")` 기본값은 유지했다.
  - legacy C2 hard reject와 constrained feedback search를 분리했다.
- `scripts/data_prep/blender/v2_realize.py`
  - `_realize_constrained()`에서 anchor/support/LOS/camera 검증, cargo/context/explicit bounded placement, M0~M4 source mask, exact collision/support/ROI 측정을 구현했다.
  - `render(..., deterministic_cpu=False)` 기본값은 유지하고 진단 runner만 deterministic CPU final RGB를 요청하도록 했다.
- `scripts/data_prep/blender/run_v2_scene_logic.py`
  - 20-frame smoke는 mode당 5장, 500-record 진단은 clean 100/cargo 100/context 150/controlled 150으로 고정했다.
  - frame/stage seed, index-safe chunk, resume-safe record snapshot, failure diagnostics, fail-closed 동작을 구현했다.
- `scripts/data_prep/blender/analyze_v2_scene_logic.py`
  - baseline 재집계, 22개 고정 차트, source occlusion/placement/runtime/gate EDA를 구현했다.
  - 실제 decoded RGB의 strict magenta 측정값을 정본으로 사용하고, RGB가 없는 failure record에서만 record metadata를 fallback으로 사용하도록 수정했다.
- `scripts/data_prep/blender/audit_v2_scene_logic.py`
  - 500개 index의 RGB/label/mask 무결성, overlay/placeholder, fatal defect, duplicate, mask monotonicity, front/connector, collision/support/camera 감사를 구현했다.
  - realize failure record는 500-record completeness에는 포함하되 존재하지 않는 RGB/label/mask를 누락 파일로 오판하지 않도록 했다.
- `scripts/data_prep/blender/compare_v2_determinism.py`
  - runtime/path/session 필드만 제외하고 record/label/decoded RGB/decoded mask를 exact 비교하는 comparator를 구현했다.

### 확인된 미해결 사항과 다음 최소 수정

1. 500 proposals 중 RGB가 435장뿐이다.
   - 원인: controlled explicit bounded search 62건 소진, anchor 3건 실패.
   - 최소 수정: `bounded_local_search_exhausted`의 best candidate score/side/asset/depth 로그를 집계하고, target side별로 search seed와 budget을 보정한 뒤 동일 20-frame exact smoke와 500-record 진단을 다시 수행한다.
2. controlled target delivery가 58%이고 center가 3/87뿐이다.
   - 최소 수정: center target을 mode allocator에서 명시 quota로 배정하고, center 전용 overlap-centroid seed를 분리한다.
3. architecture-derived minimum projected-size gate가 없다.
   - 관측: accepted frame 중 M0 mask area 100 px 미만이 12건(`4,41,125,230,246,284,290,359,392,416,467,481`)이다.
   - 최소 수정: DOPE belief-map stride와 필요한 output cell 수로 최소 projected-size를 먼저 확정하고, diagnostic manifest 또는 eligibility gate에 적용한다.
4. deterministic CPU/no-denoise 렌더에 가시적 speckle이 남는다.
   - 최소 수정: exact determinism을 유지하는 deterministic denoise 경로를 별도 smoke로 검증하거나, 샘플 수 증가 비용을 측정한다.
5. front/opening visibility가 hard eligibility가 아니다.
   - 최소 수정: 전체 공개 pool은 보존하고 `alignment_eligible` manifest에서만 ROI 최소 가시율을 적용한다.
6. low-resolution explicit mask tolerance는 최종 full-resolution hard recheck가 아니다.
   - 최소 수정: full-resolution M3/M4로 최종 side/overlap tolerance를 재검사하고 초과 프레임을 retry 또는 별도 manifest로 보낸다.
7. cargo/context 요청 개수는 부분 배치 실패를 허용한다.
   - 최소 수정: requested/placed/visible 개수를 mode별 acceptance 또는 manifest 조건으로 명시한다.
8. `occluder_side_count` aggregate metadata는 source-field mismatch로 `(missing):500`이지만 target-vs-actual chart는 별도 필드에서 정상 생성된다.
   - 최소 수정: analyzer aggregate field를 `occluder_side_actual`로 통일하는 회귀 테스트를 추가한다.
9. task 파일들이 현재 Git에서 untracked라 tracked baseline diff를 계산할 수 없다.
   - 기존 worktree가 광범위하게 dirty한 상태였으며 이번 작업에서는 관련 없는 변경을 되돌리거나 stage하지 않았다.

- production default는 `legacy`로 유지한다.
- constrained 경로는 `run_v2_scene_logic.py`에서만 명시적으로 opt-in한다.
- 40k 본렌더 승인 조건을 충족했다고 선언하지 않는다.
