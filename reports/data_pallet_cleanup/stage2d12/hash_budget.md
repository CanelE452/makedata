# Stage 2-D1.2 — hash 예산

## 승인된 한도 (사용자 지시 §6)

```
cohort                   한도
─────────────────────────────────
D12B_REFERENCE_MOVE      36 GiB
D12C_PROVEN_NOAI_MOVE    34 GiB
─────────────────────────────────
합계                     70 GiB
```

`worker=1` · `hash-mode=all` · pre + post 전수. **selective 로 낮추지 않는다**(지시 명시).

## 계획 시점 추정 (frozen_scope.json, 실측 bytes 기반)

읽기량 = 이동 대상 bytes × 2 (pre 1회 + post 1회). 파일 수·bytes 는 이동 직전 파일시스템을
다시 재서 얻었다(계획서 숫자를 재사용하지 않았다).

```
cohort                   files    bytes            추정 읽기      한도    여유
────────────────────────────────────────────────────────────────────────────────
D12B_REFERENCE_MOVE     92,429   17,334,010,020    32.287 GiB   36 GiB   3.71 GiB
D12C_PROVEN_NOAI_MOVE   39,620   15,588,789,193    29.036 GiB   34 GiB   4.96 GiB
────────────────────────────────────────────────────────────────────────────────
합계                   132,049   32,922,799,213    61.323 GiB   70 GiB   8.68 GiB
```

`within_all_limits = true`. 예산 초과 시 도구는 `HashBudgetExceeded` 로 **중단**하고
selective 로 자동 강등하지 않는다 — 강등은 지시가 금지한 동작이다.

## 실제 사용량

```
cohort                   pre-hash     post-hash    합계         한도    소진율
────────────────────────────────────────────────────────────────────────────────
D12B_REFERENCE_MOVE      16.14 GiB    16.14 GiB    32.29 GiB   36 GiB   89.7%
D12C_PROVEN_NOAI_MOVE    14.52 GiB    14.52 GiB    29.04 GiB   34 GiB   85.4%
────────────────────────────────────────────────────────────────────────────────
합계                     30.66 GiB    30.66 GiB    61.32 GiB   70 GiB   87.6%
```

추정치와 실사용이 일치한다 — 예산 초과 0, hash-mode 강등 0, unhashed 파일 0.

## 예산 밖에서 읽은 것 (별도 집계)

`filesystem_diff.json` 의 보호 영역 불변 검증은 이 예산과 별개다. D0 인벤토리의
blend·weights·package·dataset 을 지금 경로로 추적해 SHA256/크기를 재확인했고
**9.48 GiB** 를 읽었다. 문제 0건.

기존 원장 재검증(§10 F/G)도 예산 밖이다 — 원장 자신의 post-hash 재확인이며
이동을 수반하지 않는다.
